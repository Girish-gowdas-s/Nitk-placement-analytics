# Nitk-placement-analytics
Exploratory analysis of NITK placement and internship trends using Excel, SQL and Power BI.

## Project Overview

NITK placement and internship analytics project studying placement
patterns across branches, degrees, years and placement types.

## Dataset

Sanitized NITK placement/internship dataset used for portfolio analysis.


## Planned Analysis

- Year-wise placement trends
- Branch-wise placement analysis
- Degree-wise placement analysis
- Internship vs placement analysis
- PPO vs direct placement analysis
